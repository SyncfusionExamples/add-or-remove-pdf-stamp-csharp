# 3 Ways to Add Stamp in PDF Using C#

The Syncfusion® .NET PDF Library provides powerful APIs for adding and managing stamps in PDF documents programmatically. This collection of samples showcases three different methods for applying stamps, along with options to customize, flatten, or remove them, enabling developers to build approval, branding, and workflow automation features seamlessly.

Sample name | Description
------|------
[Create stamp with standard icon](https://github.com/SyncfusionExamples/add-or-remove-pdf-stamp-csharp/tree/master/add-stamp-in-pdf-using-csharp) |  Demonstrates how to add predefined standard icon stamps such as Approved, Draft, or Confidential to a PDF document for quick workflow marking.
[Create stamp with dynamic content](https://github.com/SyncfusionExamples/add-or-remove-pdf-stamp-csharp/tree/master/add-dynamic-stamp-to-pdf-csharp) | Shows how to generate stamps with dynamic text or metadata, enabling automated insertion of details like timestamps, usernames, or custom messages.
[Create stamp with image](https://github.com/SyncfusionExamples/add-or-remove-pdf-stamp-csharp/tree/master/add-stamp-with-image-in-pdf) | Explains how to insert image-based stamps, such as company logos or branded graphics, to visually reinforce ownership and authenticity.
[Customize stamp](https://github.com/SyncfusionExamples/add-or-remove-pdf-stamp-csharp/tree/master/customize-stamp-appearance) | Illustrates how to adjust stamp properties including size, color, rotation, and position to match branding or document layout requirements.
[Remove or flatten stamps in PDF](https://github.com/SyncfusionExamples/add-or-remove-pdf-stamp-csharp/tree/master/remove-or-flatten-stamps-in-pdf) | Demonstrates how to programmatically remove stamps or flatten them into the PDF content, ensuring permanent embedding or clean removal.

## How to run the examples

* Download this project to a location in your disk.
* Open the solution file using Visual Studio.
* Rebuild the solution to install the required NuGet package.
* Run the application.
